# 画面詳細設計

各画面の表示項目・入力項目・操作・権限を定める。画面一覧と遷移は [03_screen_flow.md](03_screen_flow.md)、入力 → 確認 → 完了などの共通ルールは [04_screen_rules.md](04_screen_rules.md) を参照。

画面は、機能ごとの Issue に入るときに、ここへ書き足していく。

---

## 商品管理（Issue 6）

### 商品一覧

| 項目 | 内容 |
| --- | --- |
| ファイル | public/products/index.php |
| 目的 | 商品を探して、全拠点と選んだ拠点の在庫数を確認し、商品詳細へ進む |
| 権限 | 全員（「商品を登録する」ボタンは管理者のみ） |

**検索条件**（GET で送信。検索結果の URL をブックマークでき、商品詳細から戻ったときも同じ結果になる）

| 項目 | 入力方法 | 備考 |
| --- | --- | --- |
| 商品名 | テキスト | 部分一致 |
| カテゴリ | 選択 | すべて／6種類 |
| 対象 | 選択 | すべて／女・男・子 |
| 季節 | 選択 | すべて／夏物・冬物・通年 |
| 拠点 | 選択 | すべて／利用中の拠点。選ぶと、その拠点に在庫がある商品だけを表示する |
| 廃番も表示する | チェックボックス | 初期は表示しない |

**表示項目**

| 列 | 内容 |
| --- | --- |
| 商品コード | P-0001 の形式。商品詳細へのリンク |
| 商品名 | |
| サイズ | |
| カテゴリ・対象・季節 | 日本語で表示 |
| 色・柄 | |
| 在庫数（選択拠点） | 拠点を選んだときだけ表示 |
| 在庫数（全拠点） | 拠点にある数の合計 |
| 輸送中 | 輸送中の数の合計 |
| 状態 | 廃番のときだけ「廃番」と表示 |

- 在庫数は、輸送中の箱・輸送中の商品を含めない。
- 並び順は商品コード順。ページ分けはしない。
- 拠点ごとの内訳は一覧では表示せず、商品詳細で比べる（拠点が増えても列が増えないようにするため）。

**ボタン**：検索、条件をクリア、商品を登録する（管理者のみ）

### 商品詳細

| 項目 | 内容 |
| --- | --- |
| ファイル | public/products/show.php?id=商品ID |
| 目的 | 商品の情報と、拠点別・箱別・輸送中の在庫を比べ、その場で在庫の操作に進む |
| 権限 | 全員（編集・廃番・利用中に戻すは管理者のみ） |

**商品の情報**：商品コード、商品名、サイズ、カテゴリ、対象、季節、色、柄、備考、状態

**在庫の表**（拠点ごとに小計の行を入れる）

| 拠点 | 保管場所・移動 | 数量 | 操作 |
| --- | --- | --- | --- |
| 本部 | 箱なし | 2 | 出庫 ／ 保管場所変更 ／ 移動 |
| | **小計** | **2** | |
| 奈良店 | 箱なし | 3 | 出庫 ／ 保管場所変更 ／ 移動 |
| | BOX-0006 | 1 | 出庫 ／ 保管場所変更 ／ 移動 |
| | **小計** | **4** | |
| 輸送中 | 奈良店 → 大阪店（10/20 発送） | 1 | 移動詳細を見る |
| | **小計** | **1** | |

表の下に、数の内訳を1行で表示する。

> 全拠点の在庫 7 ／ 輸送中 1 ／ 総数 8

- 在庫がない拠点は表示しない。
- 保管場所が箱のときは表示コード（BOX-0006）を表示し、箱詳細へのリンクにする。
- 操作のボタンは、商品と保管場所を入力済みにして各操作画面を開く（リンク先は各機能の Issue で作る）。
- 輸送中は、次の2つを合わせて表示する。データがなければ輸送中の行は表示しない。
  - 商品移動の明細のうち、状態が輸送中のもの
  - 状態が輸送中の箱に入っている、この商品の数
- 総数は「拠点の在庫 ＋ 輸送中」で、会社が所有しているこの商品の数（要件定義書 3章の前提）。

**ボタン**

| ボタン | 表示する条件 | 動き |
| --- | --- | --- |
| 入庫する | 利用中の商品 | 入庫画面を開く（商品は入力済み、入庫先は所属拠点の箱なし） |
| 編集する | 管理者 | 商品編集の画面を開く |
| 廃番にする | 管理者、利用中の商品 | 同じ画面内で確認して完了 |
| 利用中に戻す | 管理者、廃番の商品 | 同じ画面内で確認して完了 |

**実装の方針**：SQL で「拠点・保管場所ごとの数」を拠点の順に取り出し、PHP で拠点ごとのグループに分けてから、グループごとに行と小計を出力する。

### 商品登録・編集

| 項目 | 内容 |
| --- | --- |
| ファイル | public/products/edit.php（登録）、public/products/edit.php?id=商品ID（編集） |
| 目的 | 商品マスタを登録・編集する |
| 権限 | 管理者のみ |

**入力項目**

| 項目 | 入力方法 | 必須 | チェック |
| --- | --- | --- | --- |
| 商品名 | テキスト | ○ | 50文字以内 |
| カテゴリ | 選択 | ○ | 登録されているカテゴリのどれか |
| 対象 | 選択 | ○ | 女・男・子のどれか。初期値は女 |
| 季節 | 選択 | ○ | 夏物・冬物・通年のどれか。初期値は通年 |
| サイズ | テキスト | | 20文字以内 |
| 色 | テキスト | | 50文字以内 |
| 柄 | テキスト | | 50文字以内 |
| 備考 | 複数行テキスト | | |

- 対象の初期値を女にする理由：商品の約7割が女性用のため、登録の手間を減らす。男性用・子供用の選び忘れを防ぐため、確認画面では対象を目立つように表示する。
- 編集では、商品コードは表示のみで変更できない。
- 任意項目が空のときは、DB に NULL で保存する。

**流れ**：入力 → 確認 → 商品詳細へリダイレクトし、「登録しました」「更新しました」と表示する（[04_screen_rules.md](04_screen_rules.md) の型）。

### 廃番・利用中に戻す

商品詳細の画面内で行う。

| 操作 | 条件 | 条件を満たさないときのメッセージ |
| --- | --- | --- |
| 廃番にする | 在庫がない、輸送中の移動がない | 在庫が残っているため廃番にできません。／輸送中の移動があるため廃番にできません。 |
| 利用中に戻す | なし | |

- 拠点の「停止・再開」と同じ考え方（止めるときだけ条件がある）。
- 廃番の商品は、商品一覧では「廃番も表示する」のときだけ表示し、在庫操作の画面の選択肢には出さない。商品詳細と履歴では、そのまま表示する。
- 1つの処理で、送られてきた操作（廃番／利用中に戻す）によって、status の値と条件のチェックを切り替える。

## 拠点管理（Issue 7）

拠点は項目が少ないため、拠点詳細の画面は作らず、一覧の中で情報と操作をまとめる。どの画面も管理者のみ。

### 拠点一覧

| 項目 | 内容 |
| --- | --- |
| ファイル | public/locations/index.php |
| 目的 | 拠点の状態と、停止できるかどうかを確認し、編集・停止・再開に進む |
| 権限 | 管理者のみ |

**表示項目**

| 列 | 内容 |
| --- | --- |
| 拠点名 | |
| 状態 | 利用中／停止中 |
| 在庫数 | その拠点にある数の合計（輸送中は含まない） |
| 箱の数 | 使用中の普通の箱の数（箱なし用の箱は数えない） |
| 所属ユーザー | その拠点に所属している、利用中のユーザーの数 |
| 備考 | |
| 操作 | 編集する、停止する／再開する |

- 停止中の拠点も、いつも表示する（拠点の数は少ないため）。
- 停止中の拠点の行は、文字と背景をグレーにして区別する。「再開する」のボタンは押せるままにする。
- 在庫数・箱の数・所属ユーザーを並べ、停止できるかどうかが一覧で分かるようにする。

**ボタン**：拠点を登録する

### 停止・再開

拠点一覧の画面内で確認して完了する。

| 操作 | 条件 | 条件を満たさないときのメッセージ |
| --- | --- | --- |
| 停止する | 輸送中の移動がない、在庫がない、使用中の箱がない、利用中の所属ユーザーがいない | 輸送中の移動があるため停止できません。／在庫が残っているため停止できません。／箱が残っているため停止できません（先に箱を廃止するか、別の拠点へ移動してください）。／所属しているユーザーがいるため停止できません。 |
| 再開する | なし | |

- 商品の廃番・利用中に戻すと同じ考え方（止めるときだけ条件がある）。
- 箱なし用の箱は、停止しても残す（再開したときにそのまま使えるようにするため）。

### 拠点登録・編集

| 項目 | 内容 |
| --- | --- |
| ファイル | public/locations/edit.php（登録）、public/locations/edit.php?id=拠点ID（編集） |
| 目的 | 拠点を登録・編集する |
| 権限 | 管理者のみ |

**入力項目**

| 項目 | 入力方法 | 必須 | チェック |
| --- | --- | --- | --- |
| 拠点名 | テキスト | ○ | 50文字以内、他の拠点と重複しない |
| 備考 | 複数行テキスト | | 1000文字以内 |

**流れ**：入力 → 確認 → 拠点一覧へリダイレクトし、「登録しました」「更新しました」と表示する。

- 登録では、拠点の追加と、箱なし用の箱の追加を、1つのトランザクションで行う。

## 箱管理（Issue 8）

箱なし（店頭など、箱に入っていない商品）も、拠点ごとに1つの保管場所として、箱一覧と箱詳細で確認できるようにする。ただし、普通の箱とは見た目を分け、廃止・箱ごと移動・メモの編集はできないようにする。

### 箱一覧

| 項目 | 内容 |
| --- | --- |
| ファイル | public/boxes/index.php |
| 目的 | 商品の条件や季節・カテゴリから箱を探して、どの拠点にあり、何がいくつ入っているかを確認し、箱詳細へ進む |
| 権限 | 全員 |

**検索条件**（GET で送信。商品の条件は商品一覧と同じ）

| 項目 | 入力方法 | 備考 |
| --- | --- | --- |
| 商品名 | テキスト | 部分一致 |
| カテゴリ | 選択 | すべて／6種類 |
| 対象 | 選択 | すべて／女・男・子 |
| 季節 | 選択 | すべて／夏物・冬物・通年 |
| 拠点 | 選択 | すべて／利用中の拠点。初期値は所属拠点 |
| 空の箱だけ表示する | チェックボックス | 再利用できる箱を探すとき用。箱なしは表示しない |
| 廃止した箱も表示する | チェックボックス | 初期は表示しない |

- 商品の条件（商品名・カテゴリ・対象・季節）は、**すべての条件を満たす商品が1つでも入っている箱**を表示する（例：季節「夏物」・カテゴリ「着物」なら、夏物の着物が入っている箱）。

**表示項目**

| 列 | 内容 |
| --- | --- |
| 箱ID | BOX-0004 の形式。箱なしの行は「箱なし」。箱詳細へのリンク |
| 拠点 | |
| 状態 | 使用中／輸送中／廃止。箱なしの行は空欄 |
| 季節 | 中身の商品の季節。複数ある場合は「夏物・通年」のように並べる。箱なしの行は「ー」 |
| カテゴリ | 中身の商品のカテゴリ。複数ある場合は「着物・襦袢」のように並べる。空の箱は「（空）」。箱なしの行は「ー」 |
| 合計数 | 中身の商品の数の合計 |
| 該当数 | 商品の条件で検索したときだけ表示する。条件に合う商品の数 |
| メモ | 箱なしの行は「店頭など、箱に入っていない商品」と表示する |

- 並び順は、拠点の順。各拠点の中では、箱なしの行をいちばん上にし、続けて箱IDの順。
- 箱なしの行は背景の色を変え、普通の箱と区別する。
- 季節とカテゴリは中身から自動で決まるため、手書きのラベルのように書き直し忘れることがない。
- 箱なし（店頭など）にはほぼすべてのカテゴリが並び、一覧が読みにくくなるため、箱なしの行では季節とカテゴリを表示しない。中身は箱詳細で確認する。
- 該当数を表示するのは、「この箱に8個入っているうち、探している商品は何個か」を分かるようにするため。

### 箱詳細

| 項目 | 内容 |
| --- | --- |
| ファイル | public/boxes/show.php?id=箱ID（箱なしも同じ画面） |
| 目的 | 箱を開けずに中身を確認し、メモの編集・廃止・保管場所変更・箱ごと移動に進む |
| 権限 | 全員 |

**箱の情報**

| 項目 | 普通の箱 | 箱なし |
| --- | --- | --- |
| 見出し | BOX-0004 | 奈良店の箱なし |
| 拠点 | 表示 | 表示 |
| 状態 | 使用中／輸送中／廃止 | 表示しない |
| メモ | 表示 | 表示しない |
| 作成日 | 表示 | 表示しない |

**中身の表**

| 列 | 内容 |
| --- | --- |
| 商品コード | 商品詳細へのリンク |
| 商品名・サイズ・カテゴリ・季節・色・柄 | |
| 数量 | 最後の行に合計を表示する |

- 中身がない場合は「この箱は空です。」と表示する。

**ボタン**

| ボタン | 普通の箱で表示する条件 | 箱なし | 動き |
| --- | --- | --- | --- |
| 保管場所変更 | 使用中で、中身がある | 中身があれば表示 | 移動元をこの箱にして、保管場所変更の画面を開く（Issue 10） |
| 箱ごと移動 | 使用中 | 表示しない | 送る箱をこの箱にして、箱ごと移動の画面を開く（Issue 12） |
| メモを編集する | 廃止していない | 表示しない | 同じ画面の中でメモを書き換えて保存する（500文字以内） |
| 廃止する | 使用中で、空 | 表示しない | 同じ画面の中で確認して完了 |

- 輸送中の箱は、中身を変更できないため、保管場所変更・箱ごと移動・廃止のボタンを表示しない。メモの編集はできる（中身には影響しないため）。
- 廃止の直前に、空であることをもう一度確かめる（確認画面を見ている間に、商品が入れられたかもしれないため）。
- メモの編集と廃止は、在庫操作と同じく全員が行える。メモの変更は履歴に記録しない。
