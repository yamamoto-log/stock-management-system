# テストシナリオ

業務の流れに沿って操作し、各段階で在庫の数が期待どおりか、記録と在庫が一致しているかを確かめる。

## 準備

1. DB を作り直す（schema.sql → seed.sql → sample_data.sql）。**開発用のデータはすべて消える。**
2. 作り直した直後の在庫は次のとおり。

| 拠点 | 在庫数 |
| --- | --- |
| 本部 | 22 |
| 奈良店 | 16 |
| 大阪店 | 7 |
| 輸送中 | 0 |
| 合計 | 45 |

3. 新しく作られる番号は、操作が #4 から、箱が BOX-0008 から始まる。

## 各段階で確かめること

| 確かめること | 方法 |
| --- | --- |
| 拠点ごとの在庫数・輸送中・合計 | ダッシュボード |
| 箱の中身 | 箱詳細 |
| 記録と在庫の一致 | `source database/check_consistency.sql` が0行 |
