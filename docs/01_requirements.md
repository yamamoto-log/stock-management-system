# アプリの目的（要約）
本システムは、着物レンタル店における商品在庫を、拠点・箱単位で一元管理することを目的とする。

店舗ごとの在庫数だけでなく、商品がどの拠点のどの箱に保管されているかまで管理することで、離れた場所に保管されている商品についても、現地へ確認しに行くことなく保管状況を把握できるようにする。

また、入出庫や店舗間移動、箱内の商品の移動を記録し、在庫数の変化を追跡可能にすることで、在庫差異が発生した際の原因を確認できる仕組みを構築する。

これにより、「どの商品が、どこに、何個あるのか」を正確かつ効率的に把握できる在庫管理環境を実現する。

# アプリの目的（全文）
## 【背景・課題】

着物レンタル店では、季節や利用シーンに応じてさまざまな商品を取り扱うため、オールシーズン分のレンタル商品を保管しておく必要がある。

しかし、立地の良い店舗などでは、店舗内に十分な在庫保管スペースを確保することが難しく、オフシーズンの商品や使用頻度の低い商品を本社へ移動して保管する運用が行われていた。

本社に送られた商品は段ボール箱などにまとめて保管されていたが、どの箱にどの商品が入っているのかを正確に把握できる状態になっておらず、必要な商品を探すために本社へ直接確認しに行く必要があるなど、在庫確認に時間と手間がかかっていた。

また、箱のラベルは手書きで管理されていたため、記載方法に統一性がなく、箱を開けなければ中身を確認できないケースも多く発生していた。

さらに、店舗間での商品移動や、忙しい時間帯に行われる商品の出し入れが記録されないことなどにより、実際の在庫数とExcelで管理している在庫数に差異が生じることがあった。

Excelの在庫表では、現在の数量を確認することはできても、「いつ・誰が・どの商品を・どのように移動したことで数量が変わったのか」を追跡することが難しく、在庫数に誤りが発生した際の原因特定にも時間がかかっていた。

## 【目的】

そこで、「どの商品が、どの拠点に、何個あり、さらにどの箱に保管されているのか」を一元的に管理できる在庫管理システムを構築する。

店舗ごとの在庫数だけでなく、箱単位で保管場所と中身を管理することで、店舗から離れた場所に保管されている商品についても、現地へ確認しに行くことなく、現在の保管状況を把握できる状態を目指す。

また、商品の入出庫や店舗間移動、箱内での商品の移動を記録し、在庫数が変化した履歴を追跡できる仕組みを導入することで、在庫数に差異が発生した場合にも原因を確認できるようにする。

## 【解決方法】
### 1. 拠点・箱単位で在庫を管理する

商品ごとの在庫数だけでなく、

どの拠点にあるか
箱なしで保管されているか
どの箱に入っているか
その箱に何の商品が何個入っているか

まで管理する。

これにより、本社を含む全拠点の在庫状況と、各箱の中身をシステム上から確認できるようにする。

### 2. 店舗間の在庫移動をシステム上で管理する

店舗間で商品を移動する際は、移動内容を登録することで、送り元の在庫を自動的に減らし、送り先の在庫を自動的に増やす。

また、受取確認の操作を設けることで、送り先店舗が商品を受け取ったことを確認できるようにし、移動中の商品や受取確認が行われていない移動を把握できるようにする。

なお、受取確認によって在庫が二重に加算されないよう、在庫更新のタイミングを明確にする。

### 3. 箱の中身の変更を管理する

商品の整理や保管場所の変更によって、箱の中身が一部入れ替わるケースに対応する。

例えば、

箱なしの商品を箱に入れる
箱から商品を一部取り出す
箱Aから箱Bへ一部の商品を移す

といった同一拠点内での保管場所変更をシステム上で記録できるようにする。

これにより、箱の中身を整理した後も、システム上の箱の内容と実際の保管状況を一致させる。

### 4. 操作履歴を記録する

入庫・出庫・店舗間移動・箱内の保管場所変更などの操作を履歴として記録する。

**「いつ・誰が・何を・何個・どこからどこへ移動したのか」**を確認できるようにすることで、在庫数に差異が発生した際に、過去の操作をたどって原因を確認できるようにする。

### 5. 利用者ごとに操作権限を設定する

ログイン機能を導入し、利用者の所属拠点や権限に応じて操作できる範囲を制御する。

一般利用者は自店舗の在庫を中心に管理できるようにし、他店舗の在庫を勝手に変更できないようにする。

一方、管理者は全拠点の在庫を確認・管理できるようにする。

これにより、複数店舗で利用する場合でも、誤操作や意図しない在庫変更を防止する。

## 【期待する効果】

このシステムによって、これまで各店舗が個別に把握していた在庫を、本社を含む全拠点で一元管理できるようにする。

特に、箱単位で商品の保管場所を管理することで、

「この商品はどこにあるのか」
「どの店舗に何個あるのか」
「本社のどの箱に入っているのか」
「その箱には何が入っているのか」

をシステム上から確認できるようにする。

また、在庫の移動や保管場所の変更を記録することで、在庫数と実際の保管状況の差異を減らし、在庫確認や商品を探すための時間・手間を削減することを目指す。
